# consciousnessModelR: Educational Simulations for Consciousness Theories

`consciousnessModelR` provides simplified computational simulations for
teaching and exploring major ideas in consciousness studies.

## Details

The package includes toy models inspired by Global Workspace Theory,
Integrated Information Theory, attention competition, broadcast
dynamics, and threshold-based models of awareness-like processing.

These functions are educational abstractions. They do not measure,
detect, or prove consciousness in biological or artificial systems.
